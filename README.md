# Utsav (working name)

A platform for the UK Hindu community: current events at mandirs near you, and
a simple seva rota for mandir committees.

- `docs/market-gaps.md` — what already exists and where the gaps are (Oct 2026)
- `docs/core-functions.md` — the two core functions, v1 scope, success criteria, build order
- `docs/launch-plan.md` — step-by-step plan from now to launch, around a full-time job
- `docs/architecture.md` — technical plan: system parts, data model, event checking, privacy, tech choices, v1 scope
- `docs/app-setup.md` — steps to go from an empty repo to a live "coming soon" app
- `docs/decisions/` — short records of hard-to-reverse decisions, with the reasons
- `docs/source/` — the original build brief (PDF) and the concept mock site
- `audit/` — the 30-mandir website audit: list, script, and how to run it
- `prototype/index.html` — clickable prototype of the two core functions (open it in a browser)

No application code yet. The next step is validation (see build order in
`docs/core-functions.md`).
